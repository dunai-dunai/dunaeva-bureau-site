# DUNAEVA BUREAU — сайт

Статичный сайт: `index.html`, `css/site.css`, `js/site.js`, изображения в `img/`.
Открыть локально: `python3 -m http.server 8000` → http://localhost:8000

Где что менять:
- цены калькулятора — объект `PRICES` в `js/site.js`;
- Telegram — константа `TG` в начале `js/site.js` и ссылки `t.me/dunai_dunai` в `index.html`;
- тексты — в `index.html` (русский в `.ru`, английский в `.en`).
