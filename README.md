# DUNAEVA BUREAU — сайт бюро дизайна интерьеров

Статичный сайт с 3D-сценой на Three.js: при скролле камера пролетает сквозь
анфиладу залов, каждый зал — раздел сайта (подход, проекты, этапы, стоимость, о бюро, контакты).

Запуск локально (нужен любой статический сервер из-за ES-модулей):

    python3 -m http.server 8000
    # открыть http://localhost:8000

- `index.html` — разметка и русские тексты
- `js/i18n.js` — английская версия текстов
- `js/world.js` — 3D-залы, объекты, траектория камеры
- `js/main.js` — скролл, проявление текста, меню; контакты — в `CONTACTS` в начале файла
- `vendor/` — Three.js r186 (MIT)
