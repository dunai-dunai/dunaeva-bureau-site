# Коворкинг — работа для ВШЭ

Формат листов: А4 альбомный, 300 dpi (3508 × 2480 px).

## Текстурная доска — `texture-board/`

- `preview.jpg` — как выглядит лист.
- `build_texture_board.jsx` — собирает многослойный PSD в Photoshop:
  **Файл → Сценарии → Обзор…** и выбрать этот файл. Папка `layers/` должна лежать рядом.
  В документе каждый образец в своей группе («01 Лепнина» …): слой-тень (Умножение)
  и образец смарт-объектом. Чтобы поставить своё фото: двойной клик по смарт-объекту →
  вставить картинку → сохранить. Текст — живые текстовые слои, палитра — отдельные круги.
- Шрифты: Cormorant Garamond (папка `fonts/`) и Inter (Google Fonts) — установить до запуска скрипта.

Образцы 01–02 вырезаны из наших черновых рендеров, 03–08 нарисованы
временно — их заменяем на фото материалов.

## Текстурная доска v2 (flat-lay) — `texture-board-v2/`

Основная версия. Образцы как физические куски: толщина, контактная и мягкая тень, нахлёсты,
рваные края. По одному образцу на материал, крупно — чтобы читалась фактура.
`build_texture_board_v2.jsx` собирает PSD так же, как v1 (каждый образец — смарт-объект, тень — слой «Умножение»).
Нарисованы временно (заменить фото): бархат горчичный, ковёр, смальта, латунь, сталь, плитка, паркет.
Из фото: лепнина, бархат в полоску.

    python3 tools/build_flatlay.py

## Пересборка

    python3 tools/build_texture_board.py

## Банк решений (запомнено для коллажей)

- Ресепшен: волнообразная стойка из лилового рифлёного стекла с подсветкой; вывеска OPUS — **переделать**.
- Рабочая зона: столы-кластеры, стеклянные кабины; рабочее кресло — белая стёганая экокожа на хроме.
- Кабины: кресло в диагональную полосу, чёрный + молочный, бронзовый каркас (`cutouts/chair-stripe-milk-brass.png`).
- Панно: в духе мозаик «Новослободской» — золотая смальта, вместо прыгуний.
- Металл: сочетаем золото (латунь) и серебро (хром).
- Отдых: кресло с оттоманкой, горчичный бархат-мохер, полированная крестовина (антресоль — небольшой второй уровень); с него берём только бархат, мрамор не берём;
  скульптурный бирюзовый столик с потёками.
- Мини-кухня: цементная плитка, графит/беж, треугольники по диагонали.
